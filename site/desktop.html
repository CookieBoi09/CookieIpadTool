Open Lint

  1. Open the disk image and drag Lint.app into Applications.
  2. Open it. This free build is locally signed, but not Apple-notarized. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway for Lint, then confirm. Don’t disable Gatekeeper globally.
  3. Export your flashcards and notes from the website, then restore each backup in the app. The app has its own local library; it does not automatically sync with the website.
